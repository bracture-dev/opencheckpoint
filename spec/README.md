# Specification

| Path                                                                       | Contents                                          |
| -------------------------------------------------------------------------- | ------------------------------------------------- |
| [`versions/v0.1.md`](versions/v0.1.md)                                     | The normative specification, version 0.1 (draft). |
| [`schema/v0.1/checkpoint.schema.json`](schema/v0.1/checkpoint.schema.json) | The JSON Schema for version 0.1 (Draft 2020-12).  |

The specification governs. The schema expresses as much of it as JSON Schema can; the semantic
rules in §8.2 cover what it cannot. If the two disagree, report it as a defect.

Published schemas are immutable. A correction produces a new version.

The schema's `$id` is `https://opencheckpoint.org/schema/v0.1/checkpoint.schema.json`, served
by the documentation site.
