# Paper

`opencheckpoint-whitepaper.typ` is the white paper; `academic-template.typ` is its layout (centered
title and authors, indented abstract, numbered sections, captioned tables, numbered references).

Build the PDF with [Typst](https://typst.app):

```sh
typst compile opencheckpoint-whitepaper.typ
```

Every number comes from a committed results file in [`../experiments`](../experiments/); Appendix B
maps each claim to its source.
