# Changelog

All notable changes to the specification, schema, conformance suite, and tooling are recorded
here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
specification follows the version policy in §5 of the specification.

## [Unreleased]

### Added

- Specification v0.1 (draft): document format, data model, extensions, validation levels,
  semantic rules, producer and consumer requirements, security and trust model, privacy.
- JSON Schema for v0.1 (Draft 2020-12).
- Conformance manifest with valid, schema-invalid, semantic-invalid, and transition fixtures.
- Behavioral continuation scenarios for four domains.
- Example checkpoints: financial analysis, business operations, customer support, software
  development.
- RFCs 0001–0005: problem and scope, existing standards, architecture decisions, compaction and
  restoration, threat model.
- Documentation site (Astro Starlight).
- Governance, contribution, security, and stewardship documents.
